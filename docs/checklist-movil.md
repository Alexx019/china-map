# Lista de comprobación en cada móvil

Hacerla **en España, con wifi, antes de salir**, una vez publicada la web en la Pi. Cada uno en su móvil.

## 1. Instalar

- [ ] Abrir la web y poner la contraseña.
- [ ] iPhone: Safari → Compartir → «Añadir a pantalla de inicio». Android: Chrome → menú → «Instalar aplicación».
- [ ] Abrir **la app instalada** (no el navegador). Si vuelve a pedir la contraseña cada vez, avisar: habría
      que cambiar la contraseña por una página con cookie.

## 2. Guardar para usar sin conexión

- [ ] En la hoja de la región (abajo), «Guardar en el móvil». Esperar a «Listo para usar sin conexión».
- [ ] Modo avión → cerrar la app del todo → abrirla: tiene que salir el mapa, las fichas y las fotos.
- [ ] Quitar el modo avión.

## 3. Amap (lo más importante)

Con Amap (高德地图) instalado:

- [ ] Ficha de un sitio de **Shenzhen** (p. ej. Parque Lianhuashan) → «Ir con Amap» → ¿abre Amap con el
      destino en el sitio correcto?
- [ ] Ficha de un sitio de **Hong Kong** (p. ej. Monster Building) → igual.
- [ ] Si el destino sale **desplazado unos cientos de metros**, avisar: hay que convertir las coordenadas
      a GCJ-02 (ver CLAUDE.md).
- [ ] Probar los tres modos: a pie, transporte, taxi.
- [ ] Un sitio «sin ubicar» (p. ej. Librería Zhongshuge) → tiene que abrir la búsqueda por nombre.

## 4. Compartido entre los cuatro

- [ ] Marcar un sitio como «Queremos ir» (la primera vez pide el nombre).
- [ ] En otro móvil: pestaña Guardados → tiene que aparecer (como mucho en un minuto, o al volver a la app).
- [ ] Crear una ruta con 2–3 sitios, ordenarla, y verla desde otro móvil.
- [ ] Abrir un tramo de la ruta en Amap.

## 5. Ubicación

- [ ] Botón de ubicación del mapa → ¿el punto azul sale donde estás? (En China algunos navegadores dan
      coordenadas desplazadas; si pasa, apuntarlo.)

## Si algo falla

Anotar: móvil y sistema (iPhone/Android y versión), navegador, qué se hizo y qué pasó. Una captura ayuda.
